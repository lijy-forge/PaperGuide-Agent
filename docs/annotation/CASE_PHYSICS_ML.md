# 用例：物理机理嵌入机器学习预测流变性质

**文件**：`evals/paperguide/cases/retrieval/physics-informed-rheology-ml.yaml`

**问题**：如何把物理机理（本构方程、守恒律、或物理导出的描述符）嵌入机器学习模型来预测流变性质？

## 判据

**纳入**：模型中显式包含本构方程、守恒律或物理导出的描述符，物理知识以可辨认的形式
参与建模过程本身。

**排除**：纯黑箱回归（物理只体现在特征挑选的经验判断上）；传感器硬件与实验表征；综述。

## 标注（9 篇，分两个子类）

子类记录在用例的 `subgroups` 字段里，可以分别算召回率。**两组在检索上的难度可能不同**：
「物理进方程」这一类标题里常有 physics-informed、PINN 这类显式词汇，「物理进特征」
则往往只体现为描述符或混合建模，词面线索更弱。如果两组召回率出现明显差距，那说明
检索依赖的是词面匹配而非语义理解——这本身就是个有价值的观察。

## 两处标识符修正

**贝叶斯反演那篇**：原给的 `10.17863/cam.113320` 经 doi.org 内容协商核实，标题是
`Research data supporting: "Learning rheological parameters..."` —— **指向的是配套
数据集，不是论文**。检索源不会返回数据集，放进标注集会造成永久漏检。已替换为期刊版
`10.1017/jfm.2025.92`（Journal of Fluid Mechanics, vol 1011），卷号与作者所述一致。

**nn-PINNs**：DOI 结尾 `G` 修正为 `C`（`10.1039/d1sm01298c`），已核实指向
`nn-PINNs: Non-Newtonian physics-informed neural networks for complex fluid modeling`。

九条 DOI 全部通过 doi.org 内容协商核实，返回标题与简称吻合。

## 边界判例

这些是**明确排除**的类型。它们同时是决策评测的现成负样本——主题相邻、检索会返回，
但不回答这个问题。

| 类型 | 为什么排除 |
| --- | --- |
| 微流控流变仪、Raman/NIR/MIR 光谱测粘、ML 微流控传感 | **本用例最容易争的一条**。物理进的是实验设计，不是模型；模型本身是 PLS 或黑箱回归。明确划在外面 |
| 流变学数据驱动方法综述 | 检索目标是可直接使用的方法，不是领域导览 |
| 锂电极浆料、MEMS 粘度传感、钻井液实时测量、超声传感、流环表征 | 无学习成分 |

`10.1122/1.5500123` 已从候选池删除：论文不存在。
