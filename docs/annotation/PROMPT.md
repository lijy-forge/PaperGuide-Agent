# 复核用提示词

把下面这段 + `REVIEW.md` 里的某一节，一起贴给另一个大模型。

一次只贴一节。两节混在一起会让它在两个不同的问题之间摇摆。

---

```
你是某个领域的资深研究者。我在为一个论文检索系统构建评测标注集，需要你复核我的判断。

标注集的用途：给定一个研究问题，检索系统返回一批论文，我用标注集计算召回率——
标注为「该纳入」的论文有多少被检索到了。所以标注错误会直接让这个指标失去意义：

- 把不相关的论文标成「该纳入」→ 系统永远达不到高召回，指标虚低
- 把相关的论文标成「不该纳入」→ 系统漏检也看不出来，指标虚高

判断标准只有一条：

  如果一个做这个方向的研究者提出这个问题，这篇论文没有被检索到，算不算漏了？

  算漏 → 该纳入
  不算 → 不该纳入

请注意几点：

1. 判断依据是「是否回答这个具体问题」，不是「是否属于这个大领域」。
   同领域但研究的是另一个子问题，应判为不该纳入。
2. 综述类论文要单独考虑：它覆盖面广，但未必直接回答某个具体问题。
3. 只有标题可用时，如果标题信息不足以判断，请明确说「无法判断」，
   不要猜测。我会去查原文。
4. 宁可严格。标注集是尺子，少量高置信度的条目比大量边缘条目更有用。

输出格式（每篇一行，不要输出其他内容）：

  序号 | 同意/不同意/无法判断 | 一句话理由

最后另起一段，列出你认为我判断有误的条目编号，以及其中你最有把握的三条。
```

---

## 拿到结果之后

它给的是**第二个判断，不是最终答案**。处理方式：

- **它和我一致** → 直接采用
- **它不同意，理由具体** → 大概率它对，我按它的判断改
- **它不同意，理由笼统**（"这篇也相关"）→ 你来定，你读过论文
- **它说无法判断** → 去查摘要，或者直接剔除。**标注集里留着存疑条目，比少几条更糟**

改完告诉我编号，我更新用例文件。
